# Group4-Sensor-Monitoring-Network
Group 4 project – Sensor Monitoring Network implemented using Python OOP.

Scenario:
An engineering laboratory monitors equipment using digital sensors.
Each sensor has an identity, a location, a unit of measurement, a
current reading, and lower/upper limits that define its acceptable
range. Technicians update a sensor with new readings, and the system
reports whether the reading is normal, too low, or too high, and
whether that situation counts as an alarm.
Project Objectives

- Monitor sensor readings in real time.
- Identify whether sensor readings are normal, too low, or too high.
- Detect situations that should trigger an alarm.
- Apply Object-Oriented Programming (OOP) concepts in Python.

## Features

- Sensor identification
- Sensor location tracking
- Measurement units
- Current sensor readings
- Lower and upper acceptable limits
- Reading status detection
- Alarm detection

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Git and GitHub

## How the System Works

1. A sensor is created with its identity, location, unit, reading,
   and acceptable limits.
2. A technician updates the sensor reading.
3. The system compares the reading with the lower and upper limits.
4. The system determines whether the reading is:
   - Normal
   - Too low
   - Too high
5. The system determines whether an alarm should be triggered.
